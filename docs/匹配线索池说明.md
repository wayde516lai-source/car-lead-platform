# 匹配分发：选择线索

仅展示当前至少可以匹配一项执行中需求的线索。使用与预览、确认分发一致的规则，排除过期、待核验、停用、已删除、售卖次数用尽以及没有合规候选需求的记录。选择具体需求和项目后仍会再次检查，不保证每条展示线索都符合任意需求。

表格列：选择、编号、城市、品牌、车型、已匹配媒体、项目。已匹配媒体显示不同最终媒体的数量，项目包含历史售卖及待发送预占项目。

筛选项：编号、城市、品牌（支持搜索）、车型（与品牌关联）、已匹配媒体数量、已匹配媒体名称、项目。已匹配媒体选项直接读取本组织「合作与渠道 → 线索供应」中合作角色为媒体的记录，与当前线索是否已经匹配该媒体无关，新增媒体刷新后即可选择。支持组合筛选、重置和20/50/100条分页。未匹配、尚无项目可单独筛选；媒体和项目同时筛选时必须出现在同一条售卖/预占记录上。

字段与筛选均遵循账号字段权限。未授权字段不返回、不展示，也不能用于推断过滤。跨页或筛选时保留仍符合规则的选择，已经不可分发的选择自动移除。

接口：GET /api/v1/matches/leads，需dispatch权限。筛选在分页前执行，支持page、page_size、lead_no、city、brand、model、sales_count、matched_media、project、selected_ids。selected_ids返回仍有效的已选ID，避免跨页选择丢失或保留已经过期的记录。

## 2026-11-26 车型比较调整

最终确认：其他匹配规则保持不变，仅取消具体车型的线索品牌/车厂名称校验，车型比较忽略特殊符号及空格，兼容全角和大小写，保留型号字母、数字（铂智7与铂智8不同）。不扩大候选列表：城市、额度、时效、去重、售卖上限、项目、路由、发送开关、字典和权限等原有条件继续生效。全系需求仍沿用原品牌范围，不能把全系变为所有品牌。

预览、创建和发送按最终媒体车型库的唯一车型解析媒体品牌、厂商和协议要求的编号，不用线索原品牌文字作为前置门槛。必填编号歧义或缺失时不猜测，仍拒绝分发。软米会员只上报城市和车系，易车直连还需厂商；其他媒体沿用其已实现适配器要求。
