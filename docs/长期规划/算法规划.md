# 算法规划

当前不实现算法。以下数据从V1开始积累，V2先建指标，V3再建模，V4优化。预测对象均以组织隔离、业务授权及当时可用信息为边界。

| 模型 | 样本粒度与输入 | 标签/输出 | 基线与评估 |
|---|---|---|---|
| 垂媒历史需求及需求量预测 | 媒体×主体项目×周期；成功观测、需求版本、有效期、目标/剩余额度、同步覆盖 | 未来日/周新增需求或执行目标，分别建模，输出区间 | 同星期季节朴素值；滚动回测MAE/WAPE及区间覆盖；零需求不用MAPE |
| 品牌车系省市趋势 | 时间×标准维度版本，需求范围、供给及观测覆盖 | 各层级需求变化及占比 | 分层汇总一致性、方向准确度；稀疏城市回退省/品牌，不将全国量复制到每市 |
| 多垂媒重叠与一卖多价值 | 线索×决策时点的可达媒体集合、规则限制、联合结果、价格 | 组合期望净收益、相对最佳单卖增量 | 规则合法集合+单卖基线；组合收益误差和约束违规率；不能假设媒体结果独立 |
| 渠道质量/入库率/有效率 | 采集记录或交付同期群，渠道版本、品牌地区、接入拒绝、媒体结果 | 接入通过、最终入库、最终有效三个标签 | 分组平滑比例；PR-AUC/Brier/校准误差，按渠道及媒体分层；回调待定不是负样本 |
| 线索时效衰减 | 线索×发送年龄，采集/接入/首次发送/反馈时间和未发送原因 | 随等待时间的有效或计费概率 | 年龄分桶及生存分析基线；生存校准/时间分桶误差；处理右删失和选择偏差 |
| 预期利润 | 线索×候选组合×时点，计费概率、价格版本、成本/费用/退款 | 期望收入减采购及费用，含不确定区间 | 校准概率×价格规则基线；利润误差、分位误差、真实结算回测；缺成本不出确定利润 |
| 采购成本上限 | 渠道批次×线索类型×时点，组合收入分布、风险、预算和目标利润 | 可接受最高采购价 | 上限=风险折减后期望可计费收入−其他增量成本−目标利润−机会成本；可为不采购，离线测收益/预算风险 |
| 智能匹配与分配 | 每个决策时点的候选集、库存、额度、预算、价格及概率 | 选择、排序及不分配理由 | 现有共享规则为基线；满足率、净收益、等待时间、约束违规率；规则约束永远先于评分 |

## 样本与实验门槛

标签来源明确区分媒体原始、乙方转报、人工、模拟；模拟不得混入生产训练。观察成熟窗口按媒体反馈分布及业务周期核定，记录 label_as_of、late_event 和 unknown，不凭空指定固定天数。迟到回调重建标签版本，预测时点后获知的结果不可进入特征。

按时间滚动训练/验证/测试，相关线索及重复采集避免跨集合泄漏；只用 recorded_at不晚于预测时点的数据。需求预测不能拿实际交付量当真实需求；缺货、额度封顶和来源中断是截断而不是低需求。记录未选择及拒收样本，但不制造未发送线索的反事实有效标签。

渠道、地区和多媒体结果有选择偏差，离线拟合不证明因果或增量利润。先记录决策曝光及选择概率（适用时），再评估倾向校正；实验须经业务授权且不突破授权、预算、配额和售卖约束。

模型登记：用途/授权、数据及特征版本、训练区间、标签成熟窗、离线基线与分层指标、模型版本、上线范围、监控阈值和回退规则。数值门槛在基线形成后核定；未成熟或稀疏群体回退规则。上线顺序为离线→影子运行→人工辅助→授权小范围自动决策。漂移、校准恶化、约束冲突或数据断流时停用模型评分并回退现有规则，不直接修改历史预测。
