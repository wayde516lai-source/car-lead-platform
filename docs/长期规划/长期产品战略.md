# 长期产品战略

## 产品演进

- V1.0 汽车线索管理系统：可靠采集、授权核验、需求执行、匹配分发、回调、配额和经营事实留存。当前不开发预测算法，但必须从第一版开始完整积累未来建模需要的历史事实。
- V2.0 数据经营分析系统：按媒体、主体项目、渠道、品牌车系、省市和时间形成可对账的需求、供给、质量、时效、成本与结算分析。
- V3.0 预测与智能决策系统：需求预测、质量及时效预测、预期利润和采购成本上限，先离线评估，再影子运行及人工辅助。
- V4.0 供需优化与利润优化系统：在授权、去重、媒体售卖上限、KA限制、预算与需求配额内，优化采购和多媒体分配的组合利润。

## 不可丢失的建设原则

业务当前状态服务交易，历史事实服务复盘，两者必须同时维护。订单在本系统主要对应 demands（采购需求），交付对应 deliveries；未来若新增商业订单应独立建模并显式关联，不能把需求、交付、发送尝试混成一个订单。

订单创建、变更、暂停、移除、重现、完成和冲正，线索接入及拒收、匹配候选和未选原因、上报尝试及失败、未知结果、回调和冲突、采购成本、计费依据、结算及退款，均须保留可追溯历史。修正通过新事件或反向账目完成，不能只覆盖历史。个人信息按授权和最短必要期限管理，分析留存不等于无限期保留个人信息。

经营指标依次追求：数据可追溯与一致性、需求满足和线索质量、单位线索利润、预算内组合利润。不得通过减少未决样本、将失败删掉、重复计售卖或把未结算应计收入当实收来提高指标。

商业验收目标值、预测周期、数据保留期限和优化预算须按实际合同、业务周期及授权确定，目前未核定。每阶段先建立基线，再确定量化目标，不以任意准确率或样本数承诺效果。
