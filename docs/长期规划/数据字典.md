# 数据字典与指标契约

基线：本仓库迁移001—029及业务源码静态审查，未查询本地或生产业务库。下列为分析所需核心资产字典，精确现有DDL以迁移及_migrate为准；目标字段均未实施。TEXT时间沿用UTC ISO 8601，业务日Asia/Shanghai；金额INTEGER人民币分；数量INTEGER；外部编号TEXT。新增字段不得未经迁移直接使用。

## 现有资产

| 表/粒度 | 核心字段与类型 | 关联及分析用途 | 空值/限制 |
|---|---|---|---|
| demands / 一条执行需求 | id/org_id/demand_no TEXT，target_total/daily_limit INTEGER，quantity_basis TEXT，unit_price_fen INTEGER，version INTEGER | route_id→routes，external_project_id→demand_sync_projects；需求当前投影 | 外部编号与内部编号分开；数量口径必带；不表示逐日历史 |
| demand_versions / 需求修订 | demand_id TEXT，revision INTEGER，snapshot TEXT，created_at TEXT | demand_id+revision唯一；价格条件版本 | snapshot不是统一状态事件，不能假定所有路径已覆盖 |
| demand_sync_projects / 来源项目 | source_id/source_key TEXT，values_json/raw_json TEXT，is_present INTEGER，first_seen_at/last_seen_at/changed_at TEXT | source_id+source_key唯一 | 当前观测覆盖旧状态 |
| demand_sync_project_history / 去重内容 | source_id/source_key/content_hash TEXT，reason/created_at TEXT | 内容版本追溯 | 同内容重复发生被唯一约束合并，无run_id |
| demand_sync_runs / 同步批次 | id/source_id/status/started_at/finished_at TEXT，fetched等 INTEGER | 批次运行质量 | 批次总数不能还原逐项目每日需求 |
| leads / 意向线索 | id/org_id/series_id/city_code/channel_id TEXT，collected_at/expires_at/created_at TEXT，cost_fen INTEGER | channel_id→channels，供给及时效 | cost_fen NULL表示未知，0才是零成本；电话姓名密文及HMAC属受限数据 |
| ingestions / 来源记录 | id/channel_id/source_record_id/lead_id/status/error/created_at TEXT | channel+source_record_id按组织唯一；一线索多次采集 | lead_id可空；抛错不必然有记录，缺少全量拒收事实 |
| lead_sale_history / 导入售卖事实 | lead_id/ingestion_id/media_id/project/sold_at TEXT | ingestion_id唯一；历史售卖约束 | 与本系统deliveries来源不同，不能直接叠加收入 |
| deliveries / 单笔业务交付 | lead_id/demand_id/route_id/media_id TEXT，price_fen INTEGER，三类结果状态和各时间 TEXT | 需求/路由快照，独立交付结果与计费条件 | payload_cipher受限；ELIGIBLE不是已结算或实收 |
| attempts / 发送尝试 | delivery_id TEXT，attempt_no INTEGER，outcome TEXT，http_status INTEGER，created_at TEXT | delivery_id+attempt_no唯一 | http_status可空；缺少统一开始/结束/耗时/标准失败维度 |
| callback_events / 去重回调 | org_id/partner_id/event_id/delivery_id TEXT，occurred_at/received_at/body/status TEXT | 组织+伙伴+event_id唯一，交付可空 | body须最小化；适配器冲突可能仅记audit |
| quota_ledger / 配额变化 | delivery_id/demand_id/event_key TEXT，reserved_delta/valid_delta INTEGER | event_key唯一；可求和对账 | 不是收入或结算账本 |
| auto_dispatch_decisions / 当前决策 | org_id/lead_id/status/candidates/reason/updated_at TEXT | 主键org_id+lead_id | UPSERT覆盖旧决定，不能重放历史选择 |
| consents / 接收方授权 | lead_id/recipient_id/evidence_ref/granted_at/expires_at/revoked_at TEXT | 每线索接收方唯一 | evidence_ref受限，撤回可空；不是完整授权版本史 |
| privacy_requests/notices、audit_log | 请求/通知/审计ID、组织、动作与时间 TEXT | 隐私处理和操作依据 | 必须控制自由文本，不替代领域事实 |

## 目标增量字段（建议逻辑实体，表名待实施ADR确定）

所有新增事实复用数据架构的公共事件信封；org_id和内部关联ID必填（无法识别对象的拒收事件允许业务ID空并注明原因），事件时间未知允许空，recorded_at必填。金额未知允许NULL并记录missing_reason，不能默认0。

| 逻辑实体/粒度 | 目标字段及类型 | 来源、关联与约束 | 隐私级别 |
|---|---|---|---|
| 需求观测 / 每成功批次每项目 | run_id/source_project_id TEXT，observed_at/effective_from/effective_to TEXT，presence TEXT，quantity INTEGER，quantity_basis TEXT，period_start/end TEXT，dimension_version TEXT | 同步成功事务；关联来源/需求版本；批次+项目唯一，日/月额度分列 | 内部经营；原文单独受限 |
| 状态事件 / 每次转移 | aggregate_id TEXT，from_state/to_state/reason_code TEXT，dimension TEXT，source_event_id TEXT | 需求、线索、交付、授权各写入路径；对象版本唯一；保留冲突而非替换 | 内部可关联 |
| 接入观测 / 每次请求或批次行 | request_id/batch_id/channel_id TEXT，row_no INTEGER，received_at TEXT，result/reason_code TEXT，ingestion_id/lead_id TEXT可空 | 校验失败也落最小无个人信息记录；重试单独标识、来源业务记录另去重 | 内部，禁存原电话/姓名 |
| 决策记录 / 每次选择 | decision_id/lead_id TEXT，candidate_demand_version_ids JSON，constraint_results JSON，selected_ids JSON，policy/model_version TEXT，feature_as_of TEXT，score JSON | 预览/手动/自动区分；候选集、快照、决策与交付关联 | 内部可关联，特征须授权 |
| 成本账本 / 每计费行 | entry_id TEXT，lead_id/ingestion_id/channel_id TEXT，amount_fen INTEGER有符号，currency TEXT，basis/contract_version TEXT，reversal_of TEXT可空，occurred_at TEXT | 采购凭据；明确按采集或线索计费，来源凭据行唯一 | 财务受限 |
| 结算账本 / 每确认或调整行 | delivery_id/statement_id/line_id TEXT，entry_type TEXT，amount_fen INTEGER有符号，confirmed_at/paid_at TEXT可空，reversal_of TEXT可空 | 应计、确认、实收、退款分层；账单行唯一，外部凭据脱敏 | 财务受限 |
| 维度版本 / 每有效区间 | dimension_id/version TEXT，valid_from/to TEXT，source_code/name TEXT，mapping_version TEXT | 品牌车系省市、媒体项目渠道映射；历史事实引用版本 | 内部经营 |
| 特征/预测 / 每对象每决策时点 | dataset_version/model_version TEXT，as_of_at TEXT，horizon INTEGER及单位，prediction/interval REAL，feature_version TEXT，label_mature_at TEXT可空 | 只使用当时已获知且授权的数据，保留训练覆盖区间 | 受控分析 |

## 指标口径

| 指标 | 分子/分母与粒度 |
|---|---|
| 需求量 | 媒体+主体项目+品牌车系+地区+需求周期的有效目标；库存式剩余额度与新增下单流量分开；同期多次拉取不能相加 |
| 渠道接入通过率 | 已通过业务校验的去重来源记录 / 所有可识别来源记录；另列请求失败率，避免重试放大分母 |
| 媒体入库率 | 已确认入库交付 / 已发送且观察窗成熟的交付；按采集同期归因渠道，未知另列 |
| 有效率 | 最终有效交付 / 已发送且成熟交付；另列有效/入库条件率，二者不得混名 |
| 需求重叠 | 同时有效且授权可达的媒体候选集合交集/并集；按线索及当时维度计算，区别理论交集和实际多卖 |
| 时效 | 首次上报时间减采集时间；另列入库延迟、回调延迟，负值进入质量异常 |
| 利润 | 线索组合可计费收入减一次实际采购成本及明确可变费用；应计利润、结算利润、现金收支分列；成本缺失不算零 |
| 一卖多增量价值 | 合规组合净收益减同线索最佳单媒体净收益；考虑相关性和机会成本，禁止将乙方与最终媒体重复计收入 |

指标发布必须附口径版本、时间窗、去重规则、观察成熟策略、未知比例、模拟排除条件和历史覆盖范围。业务截断或删除导致不可比时标注断点。
