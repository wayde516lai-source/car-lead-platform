## 维护要求

后续涉及数据库、接口、业务流程或产品规划，开始前必须阅读本入口、战略、数据架构、数据字典、架构决策和所涉领域文档；涉及模型同时读算法规划。重要功能交付必须同步更新路线图、数据字典及相关架构文档和 docs/CHANGELOG.md；若无变化，在交付说明逐项说明原因，不能静默跳过。

每项重要功能在PR中记录：关联差距编号、阶段状态、事实粒度、组织与业务关联键、事件和入库时间、历史及幂等策略、字段及指标变更、隐私用途与期限、旧数据兼容及回填边界、验证证据。产品职责维护路线图和指标，技术职责维护字典和ADR，数据/隐私职责复核授权、质量与期限；人员尚待项目指定，不能虚构审批人。实现者先更新，PR审查者复核。每次阶段验收及重大数据契约变更复审全套规划。

状态统一使用：规划、实施中、已验证、已发布、阻塞。完成本次文档不将任何改造标记已实现。影响硬约束的调整须新增ADR，保留旧决定和替代理由；按用户授权和现有PR流程执行，不额外引入重复确认。

文档维护验收：相对链接有效；现状与目标分开；新字段说明类型/单位/空值/来源/关联/敏感级别；重要业务变更说明历史影响；实现状态可回溯到提交和检查；无客户信息或凭证。
