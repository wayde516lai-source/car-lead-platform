## 响应处理

HTTP 2xx且errorCode=1：乙方接收存储成功，最终有效性仍PENDING。
errorCode=-1：乙方提示供应商不存在或暂停服务，发送失败。
超时、非JSON、未定义返回码：UNKNOWN，不自动重发；文档没有幂等键或查单接口，重试可能重复提交。
