# 运营总览统计口径

更新日期：2026-11-15。

- 累计入库线索：本组织线索记录总数，含已过期、已停用和已删除的记录；同一条线索多次分发仅计一条。
- 可分发条数（原“当前可匹配线索”）：至少符合一项执行中需求以及当前分发规则的线索数。与匹配分发页面不选采购主体、未加筛选时使用相同的资格判断；每条线索只计一次。会检查有效期、品牌车型地区、合同与路由、授权、售卖次数、KA限制、媒体去重以及配额等。统计为当前快照，不预占配额；创建分发仍会重新校验。
- 累计创建分发：业务分发记录总数，包含排队、失败、取消等状态；技术重试不新增业务分发记录。
- 媒体判定有效：已经发送且最终有效性标记为VALID的分发笔数；同一线索给不同媒体均判有效时分别计数。目前本地测试环境显示模拟结果。

保留报表API原有ready字段（库存状态READY且未过期），新增matchable字段供总览使用，以免改变其他报表的既有口径。总览与匹配页共用_matchable_lead_rows，避免各自维护不同规则。


## 2026-11-23：下单量级与需求列表汇总

- 总览新增“下单量级”，统计范围与需求总数一致：本组织当前需求，包含已结束/暂停等状态，不含原表已移除需求；按采购主体计一次，不因多城市或乙方转发重复乘算。
- DAILY需求的target_total以“条/日”相加；TOTAL需求的target_total以“条/项目”相加，两类并存时分列显示。统计下单目标，不扣减有效量或在途量，也不按开始结束日期外推项目总量。
- 需求池首个需求列表底部增加品牌数、城市数及下单量。按当前筛选后的全部原表/Excel需求统计，在分页之前汇总，翻页不改变统计；改变合作商、品牌、车型、城市或匹配状态时重新计算。
- 品牌沿用norm去重；多城市拆分并按city_name规范“上海/上海市”等后去重。“全国/不限/全部地区”不作为具体城市，另提示全国需求条数，不推测全国城市总数。
- 列表下单量按来源quantity_basis与每条原始“下单量”统计；非法或未配置的数量不计入总量，并显示待校验行数。列表范围只包含当前原表存在的记录，不含已移除项目。


## 2026-11-23：停用项目范围修订（本地待发布）

当前需求总数、品牌数、下单量及需求池汇总排除合作主体总开关关闭或合作项目停用的需求；仍可包含启用项目下逐条已结束/暂停的需求状态。“项目停用”与“单条需求暂停”是不同范围。主体数量维持包含已停用主体的既有口径；历史入库、分发和媒体有效统计不因项目停用而删除。


## 2026-11-23：可匹配条数与可分发条数（仅本地）

- 可匹配条数：本组织有效READY且未过期的线索，至少命中一项ACTIVE且未移除需求的时间、线索年龄、品牌、车型及城市条件。主体/项目停用、路由关闭、分发关闭、历史售卖限制或配额不足不会抹去基础候选。逐条需求自身PAUSED/CLOSED或不在执行时间内仍排除。每条线索计一次。
- 可分发条数：在基础条件之上，继续通过主体项目、路由、通道、来源/合同、授权/独家/风险、全局开关、售卖限制及配额等完整规则。与匹配分发页候选池共用规则，每条线索计一次。
- reports/funnel新增business_matchable与dispatchable，旧matchable字段保留完整可分发口径，避免已有调用方静默变化。基础匹配规则提取自_block，两项共用_basic_match_block，不改变实际创建和发送校验。
