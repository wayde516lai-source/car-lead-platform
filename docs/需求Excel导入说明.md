# 需求池 Excel 导入

更新：2026-11-18。入口：需求池 → Excel导入 → 下载Excel模板/选择文件 → 开始预检 → 确认导入。

## 必填配置与字段

与链接新增来源共用DemandSync.validate_config：合作主体、最终媒体、合作项目（会员/KA）、来源名称必填；数量口径可选每日需求量或项目时间内总需求量，默认每日。交付路由可显式选择，或按主体与媒体自动查找；无可用映射时整批不入库。文件来源不需要链接、同步频率或定时开关。

表格首行为表头，逐行必填：品牌、车型、城市&地区（也接受“城市”）、下单量。需求编号选填，缺列或单元格空白均保存为空。品牌名称、车系/车系名称、下单时间、需求量/数量、备注支持字段别名。需求编号应在Excel中使用文本格式保留前导零；对已填写编号，同媒体已存在编号和文件内重复编号均报错；多条空编号分别创建独立需求，不视为重复。

## 时间与数量

- 空白下单日期（或下单时间）：服务器收到文件预检请求的时间。
- 空白开始时间：同一个上传时间。
- 空白结束时间：待定；需求保持无固定截止日期。
- 已填写日期/时间保留并校验；结束时间须晚于开始时间。无时区时间按北京时间解释。
- 预检页面展示补齐后的值，延迟确认不改变该上传时刻。
- 下单量为1～9999999正整数，每日/项目累计口径与链接需求一致。

## 读取、预检与事务

仅支持未加密.xlsx，默认第一工作表，最多10MB、解压50MB、5000条需求、100列。不接收公式，先在Excel/WPS粘贴为值。空行忽略，重复表头/必填列缺失阻止预检。

预检展示前20条和逐行错误；存在错误时必须修正再上传。确认采用整批事务，任何冲突、配置失效或映射错误整批回滚。批次按组织和创建账号隔离，有效2小时，重复确认返回同一结果。确认时再次校验权限、配置与重复编号。

导入使用source_kind=EXCEL的独立来源，自动同步关闭；与腾讯文档来源共用需求映射、详情、筛选、分发与配额规则。Excel来源不提供原文链接，不出现在链接同步管理中，也不能通过API打开定时同步。导入不会把其他来源的需求标记为移除。

## 接口与存储

- GET /api/v1/demand-excel/template：下载空白.xlsx模板，需要demand权限。
- POST /api/v1/demand-excel/preview：filename、Base64 content、config，返回预检id、上传时间、正确/错误数、错误行与前20条。
- POST /api/v1/demand-excel/commit：id，返回source_id、created、uploaded_at。
- 新迁移025_demand_excel.sql：来源类型字段及demand_excel_batches预检/结果表。
- 预检与确认写审计；普通测试仅使用隔离临时数据库与模拟传输，无外部请求。

## 2026-11-18 预检失败提示修复

失败原因固定显示在导入弹窗内部，自动滚动并聚焦，不依赖会被模态框遮住的短暂toast。处理期间显示“预检中”，失败恢复按钮且保留文件。确认入库失败也在弹窗显示。数量列新增映射至下单量；当时对缺需求编号显示修正说明；后续按用户确认已调整为选填（见下节），不再报缺编号错误。

用实际报错文件只读核对：表头为品牌、车系、城市、数量，缺少需求编号。原文件未修改，未导入业务数据库。新增别名/错误提示专项用例和隔离DOM流程验证通过。

## 2026-11-18 需求编号改为选填

用户确认需求编号非必填，未提供时保持空字符串。表头可没有需求编号列，也可有列但留空。内部为每条空编号来源行分配独立键，避免多行覆盖；新迁移026增加demands.external_demand_no，NULL表示兼容历史编号，空字符串表示明确未填写外部编号。已有编号不变。

列表、匹配预览、自动候选、交付详情、公开快照和对外载荷使用实际外部编号；不把内部键伪装成媒体编号。依赖需求编号的真实对方接口仍按各自必填协议校验，不自动填造。相同导入批次确认幂等；重新上传无编号文件是新批次，不能凭空认定为同一需求。

实际四列表格在隔离数据库只预检：111条，111条通过，错误0条；未正式导入业务数据。无编号页面预检→确认→需求池展示通过DOM/HTTP验证。

## 2026-11-20 多车型、多地区

车型与城市单元格支持中英文逗号、顿号、分号、换行、半角/全角斜杠和竖线分隔。去除首尾空白、空项和重复项，不以普通空格拆分，保留宝马 X5、Sportback e-tron等名称。Excel保存规范化值，并保留原始单元格内容；与链接需求共用split_values解析。

需求列表和导入预览中的多项值显示第一项及“共N个车型/地区·点击展开”，点击弹出全部项。已有导入记录也按解析结果折叠展示，无需重新上传。长名称单行截断，计数文字折行，不将整串车型撑开表格。

匹配逻辑：车型集合内OR、地区集合内OR；品牌、车型、地区及授权/配额/售卖次数等条件之间仍为AND。全系、全国保留既有含义，不因多值处理放宽其他规则。不把一行多车型需求拆成多条需求或重复计入目标量。

验证：包含第二/第三车型、第二城市命中及未命中案例的专项检查通过；隔离HTTP+DOM验证导入、首项与总数展示、点击展开全部内容。不涉及真实媒体推送或线上发布。
